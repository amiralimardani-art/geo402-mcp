# geo402-mcp

IP geolocation for any IP address — paid via x402 micropayments (0.01 USDC/call on Base mainnet).

[![smithery badge](https://smithery.ai/badge/amir-alimardani/geo402-mcp)](https://smithery.ai/servers/amir-alimardani/geo402-mcp)

## Tools

| Tool | Description |
|------|-------------|
| `lookup_ip` | Geolocate an IP address: country, city, ISP, timezone, lat/lon |

## Usage

```json
{"ip": "8.8.8.8"}
{"ip": "2606:4700:4700::1111"}
{}
```

## Pricing

0.01 USDC per call on Base mainnet via [x402](https://x402.org) protocol.

Endpoint: `https://geo402.amir-alimardani.workers.dev`
